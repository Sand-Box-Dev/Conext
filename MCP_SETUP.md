# Notepad AI MCP and Reviewer Chat

Notepad AI exposes a reviewer chat in the web app and a read-only MCP server for Claude Desktop. Both use the same SQLite documents and passage retrieval. Answers are generated by the configured Ollama model and cite reviewer passages by page.

## Start the Notepad AI API

From `backend/`, install the backend dependencies and start FastAPI:

```bash
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

The web app's **Ask reviewer** panel uses this API. Start Ollama and make sure the model configured in `app/services/ollama_service.py` is available.

## Connect Claude Desktop to the MCP server

The MCP server uses stdio and opens the existing local database. It does not require the FastAPI server to be running. Install the MCP dependency with the backend requirements first.

In Claude Desktop's configuration file, add this server under `mcpServers`. Replace the example path with the absolute path to this repository on your computer:

```json
{
  "mcpServers": {
    "notepad-ai-reviewer": {
      "command": "python3",
      "args": ["/absolute/path/to/conext_git/backend/mcp_stdio.py"]
    }
  }
}
```

Restart Claude Desktop after editing its configuration. The server provides these tools:

- `list_reviewers`: list uploaded documents and their IDs.
- `search_reviewer`: retrieve relevant passages from one reviewer with page numbers.
- `ask_reviewer`: answer a question using retrieved passages and return citations.

The MCP tools are read-only. They do not expose arbitrary filesystem access, SQL, or document ingestion. `ask_reviewer` calls the configured Ollama model; passage search does not require Ollama.

## Run the MCP server manually

From the repository root:

```bash
python3 backend/mcp_stdio.py
```

When launched manually, MCP uses stdout for protocol messages. Avoid adding print-based logging to the server; use stderr or Python logging instead.
